# 丐帮网站 · 搜索引擎提交指引

网站地址：**https://gaibang.pages.dev**
Sitemap 地址：**https://gaibang.pages.dev/sitemap.xml**

> 说明：我已把 robots.txt、sitemap.xml、页面关键词、结构化数据全部做好并上线。
> 下面三步只是"告诉搜索引擎来抓"，必须登录各平台账号（密码都在你的 Edge 浏览器里，会自动填充）。

---

## 一、微软 Bing（对应 Windows/微软搜索、必应）

1. 打开 https://www.bing.com/webmasters
2. 点右上角 **Sign In**，用微软账号登录（你的 Windows 账号通常可以直接登）
3. 登录后点 **Add a site**（添加站点），填入 `https://gaibang.pages.dev`
4. 选验证方式时，建议选 **XML file verification**（文件验证）
   - 它会给你一个文件名（类似 `BingSiteAuth.xml`），**把文件名发给我**，我直接放进网站并推送上线
5. 验证通过后，左侧菜单 **Sitemaps** → 提交 `sitemap.xml`
6. 还可以用 **URL Submission** 手动提交首页和新闻页

## 二、360 搜索

1. 打开 https://zhanzhang.so.com/
2. 用 360 账号登录（没有就用手机号注册，1 分钟）
3. 点 **添加网站** → 填 `https://gaibang.pages.dev`
4. 验证方式选 **文件验证**，把给你的验证文件名发给我，我加进网站
5. 验证通过后，在 **链接提交 / Sitemap** 里提交 sitemap 地址

## 三、搜狗搜索

1. 打开 https://zhanzhang.sogou.com/
2. 登录（支持 QQ/微信扫码，很快）
3. 点 **添加站点** → 填 `https://gaibang.pages.dev`
4. 同样选文件验证，把文件名发给我
5. 验证通过后提交 sitemap

## 关于"搜'丐帮'能不能出现"——说句实话

- 提交后搜索引擎要**几天到几周**才会收录，不可能立刻出现
- "丐帮"是个热门词（金庸小说、百度百科等），新站想排到前面很难。想更快被搜到，建议搜更具体的词，比如"丐帮官网"
- 我已通过 IndexNow 协议持续向微软/Bing 提交（后台运行中，会自动重试）
